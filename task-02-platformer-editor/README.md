# 平台跳跃 · 关卡编辑器

从零实现的 2D 平台跳跃游戏和关卡编辑器。物理、碰撞和游戏循环都在本目录里，没有使用 Phaser 或其他完整游戏引擎。游戏和编辑器读写同一份关卡 JSON（`src/schema.ts`，格式版本 1）。

## 运行

```bash
cd task-02-platformer-editor
npm install
npm run dev
```

开发服务器默认是 [http://127.0.0.1:5173](http://127.0.0.1:5173)。构建后的静态页面：

```bash
npm run build
npm run preview
```

预览地址是 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

## 怎么玩

- 方向键或 `WASD`：左右移动。按住下方向键或 `S` 可以落下单向平台。
- 空格、`W` 或上方向键：跳跃。按住跳得更高，点按会提前落下。
- `R` 或「重新开始」：回到起点。掉出关卡、碰到危险区或敌人会失败。
- 顶栏滑条可以当场改重力、跳跃高度和移动速度。在编辑器里改动的数值会写进关卡；在游戏里改的是当前这一局的手感。
- 左侧列表切换关卡。内置三关：
  - **晨间小路**：平地、缺口上的危险区和一段单向平台。
  - **断桥钥匙**：要跳上单向桥，拿到钥匙才能进终点。
  - **巡逻哨岗**：左右巡逻的敌人，加上缺口和单向平台。

## 怎么做一关

1. 打开「编辑器」，点「新建关卡」。新关自带一块地面、起点和终点。
2. 在工具栏选固体、单向、危险、金币、钥匙、敌人、起点或终点，在网格上按住左键涂抹。右键或「橡皮」删掉地形、收集物和敌人。起点和终点各只有一个，再用对应工具点到新格子上就会移过去。
3. 拖动一笔算一步撤销。撤销 / 重做也可以用 `Ctrl/Cmd+Z` 和 `Ctrl/Cmd+Y`（或 `Ctrl/Cmd+Shift+Z`）。栈里至少保留 20 步，实际保留 80 步。
4. 数字键 `1`–`9` 和 `0` 切换工具：选择、固体、单向、危险、金币、钥匙、敌人、起点、终点、橡皮。
5. 「选择」工具可以拖动已放的物体。选中敌人后，右侧能改巡逻范围和速度。
6. 勾选地形、收集物、敌人、标记、网格、对齐辅助，可以单独隐藏一类东西。对齐辅助会在光标与起点、终点或其他物体同一行或同一列时画出整列 / 整行。
7. 滚轮平移画布，按住空格再拖动也可以平移。
8. 「试玩」在编辑器里直接跑当前关卡。`Esc` 或「停止试玩」回到编辑。失败或过关后可以再试一次。
9. 「保存」写入浏览器 `localStorage`。编辑自定义关卡时，涂抹结束也会自动保存。「下载 JSON」得到一份游戏能直接导入的文件；「导入 JSON」从文件加进关卡列表。格式不对时，底部会写出具体原因，页面不会崩。
10. 「重命名」聚焦名称框。名称、宽高和终点需要的金币 / 钥匙都在右侧。需要的数量比关卡里实际放置的多时，会提示这关目前通不了。
11. 内置关卡不能直接改写，也不能删除。松手之后，如果内容真的变了，会另存成自定义副本，列表里的内置原名保持不变。自定义关卡用「删除」，再点「确认删除」；「取消」或 `Esc` 可以收回。

编辑器导出的文件和游戏列表用的是同一个 `parseLevel` / `serializeLevel`。导入后出现在游戏和编辑器两个列表里，选中即可开玩。

## 测试

```bash
npm test          # 物理、碰撞、序列化、撤销、存档、三关确定性通关
npm run typecheck
npm run build
npm run test:e2e  # 先构建，再用 Playwright 跑编辑流程和两种分辨率
npm run ci        # typecheck、单元测试、构建、端到端
```

端到端覆盖：新建关卡、放置、保存、刷新后内容一致、试玩走到终点；连续 20 步撤销和重做；图层和对齐辅助；非法 JSON 的错误提示，以及下载后再导入。分辨率检查是 1280×720 和 1920×1080。三关通关由 `tests/playthrough.test.ts` 回放 `src/scripts.ts` 里的固定时间步输入，跑两遍，位置必须一致。

`npm run record` 用来重新录内置关卡的通关输入（`scripts/record.ts`）。日常测试不用跑它。

GitHub Actions 工作流 `.github/workflows/task-02-platformer-editor.yml` 只在 `pull_request` 改到 `task-02-platformer-editor/**` 或该工作流文件时运行：安装、单元测试、类型检查、构建、Playwright，并上传报告和截图。

## 已知限制

- 只有一种敌人：在若干格内左右巡逻。没有射击或追踪。
- 起点和终点不能删掉，只能移动。关卡格式要求各有一个。
- 撤销栈记录的是关卡内容。删除整关、切换关卡不会进撤销栈。
- 格子固定 32 像素。关卡最宽 200 格、最高 80 格。
- 没有音效、手柄和虚拟摇杆。编辑用鼠标或指针，游玩用键盘。
- 自定义关卡存在当前浏览器的 `localStorage`。换浏览器或清站点数据会丢，需要靠下载的 JSON 带走。
- 游戏模式里的物理滑条只影响正在玩的这一局；要写进文件，得到编辑器里调整并保存或下载。
