# 任务 4：操作系统进程调度器可视化模拟器

## 任务目标

从零构建一个操作系统进程调度算法的可视化模拟器。该系统必须正确实现多种经典调度算法，并以动画形式展示进程状态变化、就绪队列、运行情况和性能指标。重点在于算法正确性和可视化的教学价值。

## 必须完成的功能

### 1. 调度算法实现
必须正确实现以下算法（每种都要可独立运行）：
- 先来先服务（FCFS）
- 短作业优先（SJF，非抢占）
- 最短剩余时间优先（SRTF，抢占式 SJF）
- 时间片轮转（Round Robin，时间片可配置）
- 优先级调度（抢占式和非抢占式）
- 多级反馈队列（至少 3 个队列，可配置时间片）

### 2. 进程模型
- 进程属性：PID、到达时间、服务时间、优先级、当前剩余时间
- 进程状态：新建、就绪、运行、等待、完成
- 支持动态添加进程（在模拟运行过程中）

### 3. 可视化界面
- 甘特图展示进程执行时间线
- 实时显示就绪队列内容
- 显示当前运行进程
- 显示每个进程的状态变化历史
- 性能指标实时计算与展示：
  - 平均等待时间
  - 平均周转时间
  - 平均响应时间
  - CPU 利用率
- 支持调整模拟速度（暂停、慢放、正常、快进）
- 支持单步执行

### 4. 比较与分析
- 可在同一组进程上运行不同算法并对比结果
- 生成对比报告（表格形式）
- 支持导出模拟结果

### 5. 测试与质量要求
- 每种调度算法有单元测试，验证在标准测试用例上的正确性
- 至少包含 3 组标准测试数据，结果与手动计算一致
- 可视化组件有基本交互测试
- 边界情况测试：所有进程同时到达、单个进程、时间片为 1 等

## 严格完成标准（全部满足才算完成）

1. 所有 6 种算法在标准测试用例上结果正确
2. 可视化能清晰展示调度过程，甘特图与计算结果一致
3. 性能指标计算正确
4. 支持算法对比功能
5. 所有测试通过
6. 经过至少两轮迭代：
   - 第一轮：实现算法核心和基本可视化
   - 第二轮：修复计算错误、优化可视化清晰度、完善边界情况
7. README 包含算法说明、如何运行、测试用例解释

## 禁止事项

- 禁止算法实现与理论结果不符
- 禁止可视化与实际调度结果不一致
- 禁止省略任何一种要求的算法

## 技术栈建议

- 前端：React / Vue + Canvas 或 SVG
- 或 Python + 桌面 GUI
- 算法核心与可视化分离

## 交付物

- 可交互的调度模拟器
- 全部算法实现
- 标准测试用例及预期结果
- 测试套件
- 使用说明

## 监督要求

监督者必须使用标准测试用例验证至少 3 种算法的正确性，并检查可视化是否与计算结果一致。不通过则修复后重新验收。
